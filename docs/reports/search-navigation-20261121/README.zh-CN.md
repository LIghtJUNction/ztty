# 搜索结果连续导航：有界缓存与验证

日期：2026-11-21，Asia/Taipei。基线为
[c7c2a3e](https://github.com/LIghtJUNction/ztty/commit/c7c2a3e887a2f132f3e1e3d9e18cc0ebc16bae25)。
本次改动针对 Linux 搜索栏中连续按 Enter、Shift+Enter、F3 或 Shift+F3 的重复扫描。
应用版本仍为 0.5.2；本记录对应开发源码。

## 改动与取舍

历史文本和查询没有变化时，匹配数量与位置也不会变化。原实现每次跳转都重新扫描整个历史；
现在首次搜索沿用完整扫描，后续保存匹配总数，并按需保留最多 128 个匹配坐标。
窗口内跳转直接取坐标；跨出窗口时重新扫描到所需位置。查询、大小写模式或终端文本修订号变化后，
旧坐标失效。关闭搜索释放缓存。[实现](../../../src/search.rs)与
[界面接入](../../../src/session/view.rs)给出实际生命周期。

这是有界内存与重复扫描之间的取舍。它不保存历史文本的副本，也不构建完整结果索引。
在本轮包含首次查询及 160 次同向导航的样本中，成对耗时比为
**54.64–152.91 倍**。稀疏、密集、Unicode 和无匹配场景全部保留原始样本，
没有把窗口内的极短查询耗时解释成实际按键到屏幕的速度。
首次搜索仍可能变慢，首尾边界反复切换也可能不断填充窗口，具体结果如下。

## 首次搜索的补充诊断

正式导航 A/B 同时记录了每样本 5 次首次搜索，短批次的成对比例与独立中位数存在波动。
针对这项具体风险，另做 **7 轮、每轮 50 次**首次查询，四条路径轮转顺序，CPU 仍固定为 0。
每次缓存路径都新建并释放实际 GUI 所用的 `Box<Cache>`。
表中的 stateless 指每次完整扫描、不保留导航状态。

| 场景 | 原 stateless，ms / 次 | 新 stateless，ms / 次 | 新缓存首次，ms / 次 | 缓存相对原实现 | 仅加 inline 提示的实验，ms / 次 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 稀疏 ASCII | 2.698 | 2.831 | 3.188 | +18.15% | 2.886 |
| 密集 ASCII | 2.987 | 3.156 | 3.181 | +6.50% | 3.070 |
| Unicode 小写比较 / 软换行 | 4.288 | 4.301 | 4.346 | +1.35% | 4.253 |
| 无匹配 ASCII | 2.704 | 2.729 | 2.699 | -0.17% | 2.820 |

这里的变化比例由这张表对应的中位数计算，不与导航表的成对统计混用。
稀疏 ASCII 的首次缓存查询增加约 0.490 ms，其余三个场景变化约为 −0.2% 到 +6.5%。
单独的内联提示在不同场景中有增有减，本次生产源码保持原实现，没有加入该提示。
这项诊断能说明首次查询的实际代价，尚不能把差值完整归因到某一次分配或某个编译器决策。

[补充诊断原始数据](initial-search-diagnostic.json)与
[实际诊断源码](initial-search-diagnostic.rs)单独保留。该辅助二进制没有捕获独立哈希；
它不替代来源与产物摘要完整的正式导航 A/B。诊断前后生产源码未改动。

## 缓存内存与释放

在本机 x86_64 布局中，Hit 为 48 字节，128 个坐标为 **6,144 字节**。
Cache 结构体为 144 字节，查询键容量最多 1,024 字节；这三部分的请求字节上限为 7,312 字节。
首次搜索还未分配坐标窗口；窗口在导航需要时分配。当前样本的完整缓存请求量最高为
**6,298 字节**。

独立于计时的分配计数阶段包含 `Box<Cache>`。它在窗口填充后进行 256 次窗口内交替导航，
记录 alloc / realloc / dealloc，随后销毁缓存：

| 场景 | 首次后保留，B | 填窗后保留，B | 窗口内 256 次 alloc / realloc / dealloc | 销毁后保留，B |
| --- | ---: | ---: | --- | ---: |
| 稀疏 ASCII | 150 | 2,310 | 0 / 0 / 0 | 0 |
| 密集 ASCII | 148 | 6,292 | 0 / 0 / 0 | 0 |
| Unicode 小写比较 / 软换行 | 154 | 6,298 | 0 / 0 / 0 | 0 |
| 无匹配 ASCII | 150 | 150 | 0 / 0 / 0 | 0 |

这些数值是 Rust 分配器请求的存活字节，排除了分配器自身元数据、历史文本、渲染资源和进程其他状态，
不能当作 RSS。窗口内零分配也不代表所有跨窗口导航均零分配。
单元测试另检查最大查询长度、容量上限，以及空查询和超长查询释放已有缓存。

## 复现

在仓库根目录运行，复用已配置的共享 Cargo 输出和依赖缓存。
以下 owner lock 与本机所有受控 Cargo 批次共用，不能在已经持有同一把锁的批次内再套一层：

    flock /var/tmp/project-z-cargo-target/.project-z-cargo-owner.lock \
      python3 tools/benchmark_search_navigation.py \
      --baseline-ref c7c2a3e887a2f132f3e1e3d9e18cc0ebc16bae25 \
      --lines 12000 --samples 5 --steps 160 --first-iterations 5 --cpu 0 \
      --lockfile docs/reports/search-navigation-20261121/navigation-ab.Cargo.lock \
      --output artifacts/search-navigation-validation/replayed-navigation-ab.json

若 CPU 0 不在当前允许集合内，选择可用 CPU 并保留新环境记录。
构建从 Cargo JSON 读取真正的可执行文件，不自行拼接 target 路径，也不创建另一套 target 目录。
功能验收的完整命令、退出码和时间见 [results.json](results.json)。
本次没有安装到桌面、发布新包或修改其他项目的消费版本。
